# Add real NASA sounds

Drop audio files here with these exact names (mp3, wav, ogg or m4a):

| name | used for |
|---|---|
| `wind.mp3` | looping Mars wind (e.g. Perseverance microphone recording) |
| `footstep.mp3` | footsteps while walking |
| `click.mp3` | button clicks |
| `lock.mp3` | target lock |
| `alert.mp3` | hazard alert |
| `suit.mp3` | suit movement |

Or skip the folder: open the app -> TOOLS (display settings) -> **Sounds** -> Upload per slot (kept in your browser).
Missing slots use the built-in synthesized sound.
